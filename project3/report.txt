B. Design

hasCorrectSyntax() checks through the string one state forecast at a time, checking the code,
then any party results, then expecting either the end of the string or a comma.

hasCorrectSyntax:
    if string is empty, return true
    repeatedly:
        if next two characters aren't a valid state code, return false
        while a party result starts here:
            if it isn't 1 or 2 digits followed by a letter, return false
        if at end of string, return true
        if not at a comma, return false
        skip the comma

predictSeats first checks for errors then iteratures through the string

predictSeats:
    if syntax is bad, return 1
    if party isn't a letter, return 2
    for each state forecast:
        for each party result:
            if its party matches (ignoring case),
                add its seat count to running total
    set seatPrediction to the total and return 0
